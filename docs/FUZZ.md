# Kernel fuzzing

`scripts/fuzz/fuzz.ts` generates seeded random IR trees (primitives with random sizes and rigid/mirrored placements; booleans arranged to overlap, touch, share planes, contain, coincide, nearly coincide or be tangent; extrudes of star polygons, rounded rectangles and circles, with draft; revolves; lofts; fillets/chamfers with random selectors and radii; shells), evaluates them on solidcore in worker sessions and checks:

| Oracle | Bug when |
|---|---|
| `panic` | the kernel panics (wasm trap) |
| `eval-error` | a boolean, primitive, sweep or transform fails — the generator only makes valid input |
| `bad-volume` | `ok` but volume ≤ 0 or NaN |
| `mesh-volume` | divergence-theorem volume of the export mesh differs from the kernel's by > 2% |
| `open-mesh` | the export mesh is not closed (an edge not shared by exactly two triangles after welding) |
| `mesh-error` / `warning` | meshing fails, or evaluation reports warnings |
| `identity-union` / `identity-difference` | vol(A∪B)+vol(A∩B) ≠ vol(A)+vol(B), or vol(A−B) ≠ vol(A)−vol(A∩B) (0.2%) |
| `slow` / `hang` | one evaluation takes > 30 s / > 120 s |

Fillet/chamfer/shell errors are counted as **refusals** (often legitimate: radius too large) and tallied below. Every bug is delta-minimized (hoist children, drop operands, simplify transforms, selectors and numbers) while it keeps the same (oracle, op, message) signature, and deduplicated by that signature.

Run: `bun scripts/fuzz/fuzz.ts --minutes 25 --workers 6 --seed 1`; replay one case: `--replay <seed>`. Findings: `fuzz/findings/<id>.json` (minimal + original IR, seeds).
